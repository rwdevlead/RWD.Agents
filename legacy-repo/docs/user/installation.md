# Installation

There is no package to install.

To use this repository as a framework:

1. Clone the repository or open it in your workspace.
2. Read `AGENTS.md` and the live memory files in `memory/`.
3. Choose the prompt, skill, policy, or template that matches your task.
4. Follow the repository documentation when making changes.

If you are looking for a runtime application, this repository is not that. It is a reusable AI development framework.
