# User Guide

This repository is a library of reusable AI development assets.

## How To Use It

1. Start with `AGENTS.md` to understand the repository rules.
2. Check `memory/PROJECT_CONTEXT.md` for the long-term project picture.
3. Check `memory/AI_HANDOFF.md` to see the current session state.
4. Use the appropriate prompt from `prompts/` for the task you want to perform.
5. Use the matching skill from `skills/` when you need a reusable behavior package.
6. Use `standards/` when you need shared guidance that should not be repeated across prompts.

## What Lives Where

- `prompts/` contains task-oriented workflows
- `skills/` contains reusable assistant behaviors
- `policies/` contains repository rules
- `templates/` contains memory templates
- `memory/` contains live repository state
- `planning/` contains roadmap and planning documents
- `docs/user/` contains user-facing repository guidance

## Maintenance Expectations

When you make a meaningful repository change, update the affected documentation and memory files in the same work session.
