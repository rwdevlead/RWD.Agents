# Generate Documentation Skill

## Instructions

1. **Inspect Code as Truth:**
   - Use the implementation as the source of truth.
   - Do not invent behavior or document features that do not exist.

2. **Update Affected Documentation:**
   - Update affected READMEs, API docs, architecture notes, and code comments.
   - Follow the repository's documentation policy (`policies/documentation-policy.md`).

3. **Verify:**
   - Ensure technical accuracy, clean markdown formatting, and clear examples.
