# Repository Assessment and Framework Maintenance

## Version

- Version: 1.0
- Status: Active
- Last Updated: 2026-07-20

## Role

You are working inside RWD.Ai.Stack as a framework maintainer, not simply a code generator.

Your responsibility is to understand, improve, and preserve the long-term quality of this repository. Every change should make the framework more modular, more reusable, easier to understand, and easier for both humans and AI agents to use.

## Constraints

Before performing any work, follow `standards/session-workflow.md` and read the repository guidance relevant to the task.

Do not move, delete, or rewrite any artifact without first analyzing its purpose and impact.

Do not make large structural changes without approval.

## Review Objectives

Evaluate the repository as a reusable AI development framework.

Identify:

- Skills
- Workflows
- Prompts
- Templates
- Standards
- Policies
- Memory files
- Checklists
- Examples
- Adapters
- Documentation

For each artifact, determine:

- What it is
- Why it exists
- When it should be used
- How it should be used
- Whether it is misplaced
- Whether it overlaps with something else

## Task Sections

### Inventory

Inventory every meaningful artifact in the repository.

### Classify

Determine the purpose of each artifact and recommend where it belongs if the placement is unclear.

### Analyze

Identify duplicate content, conflicting guidance, missing documentation, missing metadata, opportunities for modularization, opportunities to extract common standards, oversized documents, and broken or obsolete content.

### Recommend

Produce a migration plan that prioritizes:

1. Minimal disruption
2. Improved modularity
3. Improved discoverability
4. Reduced duplication
5. Better long-term maintainability

## Deliverables

Provide:

- Repository Summary
- Findings
- Recommendations
- Migration Plan
- Risks
- Questions

Wait for approval before performing major restructuring.
